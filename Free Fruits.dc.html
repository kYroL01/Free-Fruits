System
Nothing ripe should rot.
Activist tone, forager-first. Map is the product; everything else is one tap from it. Repo kYroL01/Free-Fruits is empty, so this is built from scratch.

DECIDED
Points spend three ways: tier status, funding a real sapling (500 pts), unlocking rare-fruit map layers (300 pts). Verification is photo + GPS, then two community confirmations. Dark mode toggles from the map header.
NEXT STEPS
Local community chat (25 km radius + moderation), partner perks, offline map caching, empty/first-run states.
